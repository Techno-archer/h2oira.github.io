# H2O System Map — Control Architecture

## Core

**Aurora → Stack A → Stack B / Stack C → Production**

### Aurora
Discernment through reduction; controlled reasoning pipeline; evidence/inference separation; mathematical and structural integrity; sufficient-resolution termination.

### Stack A
Cognitive orchestration, governance, routing and translation between technical intake and capital structuring.

### Stack B
Scientific & Regulatory Intake Core. Converts geological, operational, ESG and regulatory material into structured, audit-traceable technical records.

### Stack C
Instrument Origination & Capital Platform. Converts validated eligible technical/economic inputs into structured liquidity and participation architectures.

## Persistence / interfaces

- Notion — institutional control plane
- GitHub — version-controlled technical and public-safe production plane
- JSON — compact Aurora/H2O state and session continuity
- Files — evidence intake / working corpus
- Outlook — external correspondence and attachment intake
- Zoom — engagement intelligence
- Web — external evidence retrieval

## Canonical flow

`Source → Ingestion Portal → Evidence Classification → Stack B → Stack A/Aurora → Stack C → Production → Artifact Registry → Engagement → SI`

## Non-negotiable boundary
Retrieved information is not automatically fact. Source provenance, classification, assumptions, transformations and inference remain explicit.

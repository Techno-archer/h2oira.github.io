# H2O Operational Repository

This directory is the controlled public-safe architecture scaffold for H2O Institutional Reasoning Architecture.

## Separation rule
This repository is currently public. **Do not place confidential client data, proprietary source documents, private correspondence, credentials, or sensitive transaction materials here.**

## Operational allocation
- `architecture/` — public-safe architecture and interface definitions
- `aurora/` — compact public-safe Aurora state/schema
- `ingestion/` — ingestion contracts and schemas; source payloads remain outside this public repository
- `notebooks/` — Notebook capability metadata and extracted production contracts, not confidential Notebook source material
- `procedures/` — versioned operating procedures
- `prompts/` — production prompts where safe to publish
- `schemas/` — machine-readable contracts
- `artifacts/` — public-safe released artifacts only
- `registry/` — version and lineage manifests

Private evidence and confidential artifacts require a private repository or controlled file store before publication.
